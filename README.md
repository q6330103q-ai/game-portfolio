# 김준식 · Game Archive

게임·프로토타입·기술 실험 17개를 소개하는 정적 포트폴리오. 실제 자료 이미지 24장과 영상 5개를 포함합니다. 설치 의존성, 외부 CDN, 추적 스크립트 없이 GitHub Pages에서 동작합니다.

## 로컬 실행

이 폴더에서 실행:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173/` 접속. 파일을 직접 열 수도 있지만 HTTP 서버에서 확인하는 것을 권장합니다.

## 파일 구성

- `index.html`: 한국어 페이지 구조, 검색·쇼릴·프로젝트 상세 대화상자
- `styles.css`: 반응형 레이아웃, 입체 패널, 스크롤·호버 모션
- `app.js`: 검색/카테고리 필터, 갤러리, 영상 탭, 모션 설정과 접근성
- `games.js`: 프로젝트 설명·특징·검증 상태·미디어 경로
- `media/`: 선별한 WebP 이미지와 H.264 MP4
- `.nojekyll`: 정적 파일 그대로 서비스

## 콘텐츠 변경

`games.js`의 `window.PORTFOLIO.games`에 프로젝트를 추가하거나 수정합니다. 각 항목은 `id`, `title`, `subtitle`, `engine`, `category`, `status`, `description`, `features`, `images`, `videos`, `featured`, `year`를 사용합니다.

이미지는 `{src, alt, caption}`, 영상은 `{src, poster, title, caption}` 형태입니다. `src`와 `poster`는 `media/` 아래 상대 경로로 지정합니다. 이미지·영상이 없는 프로젝트는 빈 배열을 유지하며, 다른 게임의 화면을 대신 쓰지 않습니다. 대표작은 배열 순서대로 표시합니다.

게임 출시·구현·검증 수준은 구분합니다. 소스만 확인된 작업을 완성 게임으로 표기하지 않습니다. 빈 템플릿, 공식 샘플, 백업 사본은 사이트의 제작 노트에 분류 기록을 남기며 별도 창작 게임 수로 계산하지 않습니다.

## 미디어 출처와 구분

- **Lucky Flick Survivor / 알까기**: 기존 Windows 실행 빌드의 타이틀·플레이·성장 화면을 직접 촬영. 늑대 캐릭터 드래그 발사 → 적 처치 → 레벨업 3택을 확인한 14초 무음 영상. 초기 개발 이미지 4장은 사용자 제작 알까기 1주차 발표 자료의 Game 뷰 영역만 추출.
- **RIFT MANAGER**: 프로젝트의 시작 메뉴·공성 HUD 캡처. 100명 로스터 자동전투 검증 GIF를 웹용 MP4로 변환.
- **STAR ELEVEN**: 프로젝트의 커리어·실제 경기 캡처. ThunderShot 스킬 연출 GIF를 MP4로 변환.
- **원형 경기장**: Unreal 프로젝트의 게임 캡처 및 기존 30초 편집 프로모를 최적화.
- **THUNDER MOTION LAB**: AI 생성 시네마틱 보간 실험. 원래 60Hz의 192프레임을 3.2초 MP4로 변환. **게임에 통합되지 않은 실험이며 실제 플레이 영상이 아님**을 사이트에 명시.
- 나머지 이미지: 각 게임 프로젝트의 개발 캡처. Greed Armor와 TomAndJerry는 엔진 내 기술·캐릭터 검토 이미지로 구분.
- Necro Climb: 기존 공개 저장소의 [정책 문서](https://q6330103q-ai.github.io/necro-climb/privacy.html)만 확인. 소스·장르·출시 상태를 추정하지 않음.

원본 프로젝트, 빌드 실행 파일, 개인 파일, 계정 정보는 게시하지 않습니다. 이미지는 용도에 맞게 축소하고 메타데이터를 제외했습니다. 게임의 외부 에셋·상표·영상 권리는 각 권리자에게 귀속되며 이 저장소는 원본 에셋 재배포 패키지가 아닙니다.

## 모션과 접근성

헤더의 모션 버튼으로 연출을 끌 수 있으며 설정은 해당 브라우저에 저장합니다. 운영체제의 동작 줄이기 설정을 반영합니다. 상세 대화상자는 키보드와 Escape로 조작할 수 있습니다. 영상은 컨트롤을 제공하며, 탭이 숨겨지거나 모션을 끌 때 재생을 중지합니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)` 설정으로 배포합니다. 사이트 주소: `https://q6330103q-ai.github.io/game-portfolio/`.

## 확인한 실행 경로

로컬 Chromium에서 전체 미디어 URL 응답, 영상 5개 실제 디코딩·재생, 검색·빈 결과·초기화, 카테고리 필터, 상세 열기·Escape 닫기, 모션 정지, 390px 모바일 상세 스크롤과 가로 넘침 여부를 확인했습니다. 개별 게임 전체를 다시 빌드·검증한 것은 아닙니다.
