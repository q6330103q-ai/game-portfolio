# 김준식 · 게임 포트폴리오

직접 만든 게임·프로토타입 23개를 소개하는 정적 포트폴리오. 최종 프로젝트 세 편(NECRO CLIMB, 한빛 감독 축구, 말랑이 보호소)을 가장 앞에 두고, 실제 자료 이미지와 영상을 함께 싣습니다. 설치 의존성, 빌드 도구, 외부 CDN, 추적 스크립트 없이 GitHub Pages에서 동작합니다.

## 선택용 디자인 시안

`concepts/round-2/`는 기존 홈페이지를 교체하지 않고 네 방향을 비교하기 위한 별도 화면입니다. 비교 페이지에서 PC·모바일 실제 캡처를 전환·확대하거나 각 데모를 열 수 있습니다.

- `concepts/round-2/a/`: 에디토리얼 — 밝은 지면에서 최종작 세 편을 나란히 비교
- `concepts/round-2/b/`: 플레이 스크린 — 작품 선택과 큰 영상 플레이어 중심
- `concepts/round-2/c/`: 게임 포스터 — 붉은 지면과 대형 타이포, 선택형 포스터
- `concepts/round-2/d/`: 크리에이터 노트 — 작품 목차와 미디어·제작 기록을 함께 읽기

각 시안은 루트의 `games.js`, `media/`, `fonts/`를 공유합니다. 별도의 데이터 사본이나 외부 에셋은 사용하지 않습니다. 시안 선택은 자동으로 홈페이지에 적용되지 않습니다.

## 로컬 실행

이 폴더에서 정적 서버를 실행합니다(예: `npx serve .` 또는 `python -m http.server 4173 --bind 127.0.0.1`).

`http://127.0.0.1:4173/` 접속. HTTP 서버에서 확인하는 것을 권장합니다. `#p=<id>`(예: `#p=necro-climb`)는 해당 게임 소개로 연결하고, `#p=lumi&section=media`처럼 구역까지 지정할 수 있습니다.

## 화면 구성(게임별 영상 중심 소개)

- Aniimo 참고 페이지의 대형 영상 구성을 바탕으로, 상단에서 고른 게임 하나의 소개와 작업 기록을 아래로 이어 읽는 화면입니다. 이전 B안의 좌우 고정 목록·상세 팝업은 사용하지 않습니다. 참고 사이트의 로고·영상·이미지는 복제하지 않았습니다.
- 상단 **분류**에서 전체 23편·최종 프로젝트 3편·장르를 고르고, **작품**에서 개별 게임을 선택합니다. 최종 프로젝트 세 편은 목록 앞에 둡니다.
- 첫 화면은 해당 게임의 첫 영상을 크게 보여 줍니다. 영상이 없는 7편은 실제 이미지로 소개하고 상세 작업 내용을 유지합니다. 다른 게임 화면이나 가짜 플레이 영상으로 대체하지 않습니다.
- 아래에는 **작업 내용 → 개발 기록(자료가 있을 때) → 영상과 화면 → 제작 노트**가 이어집니다. 상태·역할·도구·기능·상세 해설·개발 기록과 모든 미디어를 표시합니다.
- 게임 선택과 브라우저 뒤로/앞으로 가기, 직접 주소가 동기화됩니다. 구역 이동 링크도 선택한 게임을 유지합니다. 존재하지 않거나 제외된 게임 주소는 해당 작품을 표시하지 않습니다.
- 게임 전환 때 이전 영상을 정지하고 선택한 게임의 화면으로 바꿉니다. 세로·가로 영상과 이미지는 원본 비율을 유지하며, 작은 화면에서도 상단 선택 메뉴를 사용할 수 있습니다.

## 파일 구성

- `index.html`: 상단 분류·작품 선택, 게임 페이지 틀·제작 노트·메타·OG 태그
- `styles.css`: 대형 미디어 첫 화면·작업 기록·반응형·모션
- `app.js`: 게임별 렌더링, 분류·작품 선택, 주소·구역 이동, 영상 수명주기·모션 설정
- `games.js`: 프로젝트 설명·특징·검증 상태·개발 이력·해설·미디어 경로(유일한 데이터 원본)
- `fonts/`: 자체 호스팅한 Pretendard Variable(동적 서브셋 CSS + woff2 92조각)과 라이선스
- `media/`: 선별한 WebP 이미지와 H.264 MP4
- `concepts/round-2/`: 공개된 선택용 시안 네 개와 비교 페이지, 실제 화면 캡처
- `design-options/`: 로컬 디자인 시안 A–D 보관. 운영 사이트에서 참조하거나 배포하지 않습니다.
- `.nojekyll`: 정적 파일 그대로 서비스

## 콘텐츠 변경

`games.js`의 `window.PORTFOLIO.games`에 프로젝트를 추가하거나 수정합니다. 최종 프로젝트를 우선 표시하고 같은 그룹 안에서는 배열 순서를 유지합니다. 제작 노트는 `window.PORTFOLIO.notes`에 있습니다.

| 필드 | 용도 |
|---|---|
| `id`, `title`, `subtitle`, `engine`, `category`, `status`, `description`, `year` | 기본 정보 |
| `period` | 작업 기간. `YYYY.MM.DD`로 시작(예: `2026.10.29 – 11.05`). 없으면 `year`를 표시 |
| `team` | 팀 프로젝트 표기(예: `팀 프로젝트 · 우당탕`) |
| `role` | 팀 프로젝트에서 맡은 역할(상세의 '역할' 행) |
| `tools` | 제작 도구·AI 활용 표기(문자열 배열) |
| `history` | 개발 이력(문자열 배열, 상세의 '개발 기록') |
| `features` | 주요 특징(문자열 배열) |
| `details` | 작품 해설 `{title, text}` 배열. 작업 내용에 모든 해설을 표시 |
| `images` | `{src, alt, caption, pos?}` — 원본 비율을 유지하고 캡션·대체 텍스트를 표시 |
| `videos` | `{src, poster, title, caption}` — 첫 영상은 대표 영상, 전체 영상은 본문의 플레이어로 재생 |
| `final` | 최종 프로젝트(`true`). 작품 목록 우선 배치와 전용 분류 |
| `featured` | 기존 선택용 시안에서 사용하는 대표작 표기 |

`src`와 `poster`는 `media/` 아래 상대 경로로 지정합니다. 이미지·영상이 없는 프로젝트는 빈 배열을 유지하며 다른 게임의 화면을 대신 쓰지 않습니다.

## 표기 원칙

- **상태**: 직접 실행 확인, 플레이 녹화만 있음, 소스만 있음, 출시·실기기 미검증을 구분합니다.
- **캡션**: 직접 실행 캡처 / 실제 플레이 녹화 프레임 / 프로젝트 내 기존 캡처 / 에디터·자동 검증 화면 / 시네마틱·렌더·컨셉을 명시합니다.
- **AI 활용**: VARCO 3D 생성 모델, 이미지 생성 아트, AI 코딩 에이전트를 쓴 프로젝트는 `tools`와 캡션에 밝힙니다.
- **묶음과 제외**: 같은 게임의 백업·빌드 사본·이전 버전은 한 항목의 개발 이력으로 묶습니다. 빈 템플릿, 공식 샘플, 에셋 스토어 샘플, 외부 오픈소스 도구, 다른 사람의 배포본, 상용 게임은 제외합니다.
- **영구 제외(소유자 요청)**: 빈손의 여행자(THE MEMORY WANDERER), COLOR RUN(ColorRun/RunGame), VARCO FPS LAB(varcotest)은 포트폴리오에 다시 추가하지 않습니다.
- **중복 제외(소유자 확인)**: NIGHTFALL SURVIVOR는 다른 게임과 중복되는 항목이므로 제외하고, 별도 작품으로 다시 집계하지 않습니다.

## 서체와 라이선스

- Pretendard v1.3.9 (Kil Hyung-jin, https://github.com/orioncactus/pretendard) — SIL Open Font License 1.1. `fonts/LICENSE.txt`에 원문을 보존했고 바닥글에서 링크합니다.
- `fonts/pretendard-variable.css`는 배포본 `pretendardvariable-dynamic-subset.css`의 경로만 `woff2-dynamic-subset/`으로 바꾼 사본입니다. 브라우저는 페이지에 쓰인 글자가 속한 조각만 내려받습니다.
- 실행 중 외부 호스트에 요청하지 않습니다.

## 모션과 접근성

- 모션은 게임 전환, 제목·미디어 등장, 작업 내용의 스크롤 등장과 조작 피드백에 사용합니다. 모션을 꺼도 모든 내용과 선택 기능은 유지합니다.
- 상단 **모션 끄기/켜기** 선택은 `localStorage`의 `gp-motion`에 저장합니다. 저장값이 없으면 운영체제의 동작 줄이기 설정을 따릅니다. 모션이 꺼지면 대표 영상은 자동 재생하지 않으며, 방문자가 직접 재생할 수 있습니다.
- 사용자가 선택한 일시정지는 모션 설정·스크롤·게임 전환 후에도 그 방문 동안 유지합니다. 영상은 동시에 하나만 재생하고, 화면 밖이나 숨겨진 탭에서는 멈춥니다. 본문 영상 재생 중에는 대표 영상을 멈춥니다.
- 본문 영상은 재생하기 전까지 내려받지 않고 이미지는 지연 로딩합니다. 영상이나 이미지가 실패하면 해당 자료의 오류를 알리며 다른 게임의 화면으로 대체하지 않습니다.
- 분류·작품 선택은 기본 HTML 선택 상자이며 키보드로 조작할 수 있습니다. 본문 건너뛰기, 구역 이동 후 초점, 보이는 초점 표시를 제공합니다.
