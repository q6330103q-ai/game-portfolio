# 김준식 · 게임 포트폴리오

직접 만든 게임·프로토타입 24개를 소개하는 정적 포트폴리오. 최종 프로젝트 세 편(NECRO CLIMB, 한빛 감독 축구, 말랑이 보호소)을 가장 앞에 두고, 실제 자료 이미지와 영상을 함께 싣습니다. 설치 의존성, 빌드 도구, 외부 CDN, 추적 스크립트 없이 GitHub Pages에서 동작합니다.

## 로컬 실행

이 폴더에서 정적 서버를 실행합니다(예: `npx serve .` 또는 `python -m http.server 4173 --bind 127.0.0.1`).

`http://127.0.0.1:4173/` 접속. 파일을 직접 열 수도 있지만 HTTP 서버에서 확인하는 것을 권장합니다. `#p=<id>`(예: `#p=necro-climb`)로 접속하면 해당 작품의 상세가 바로 열립니다.

## 화면 구성(시네마틱 포트폴리오)

- 스토어 UI 대신 실제 플레이 영상과 캡처를 중심으로 구성한 독립적인 작품 전시 화면입니다. 어두운 배경, 큰 제목, 원본 비율의 미디어를 사용합니다.
- 처음(`#home`): 최종 프로젝트 3편의 영상 쇼케이스 → 각 작품의 큰 장면과 제작 해설 → 대표작 5편의 영상 스트립 → 전체 작품 24편 → 제작 노트. 쇼케이스는 9초마다 전환하며 작품 선택·이전/다음·일시정지를 제공합니다.
- 전체 게임(`#catalog`): 제목·부제·장르·엔진·설명 검색과 장르/최종 프로젝트 필터를 함께 적용합니다. 결과 수와 검색 초기화를 제공하며, 상세에서 돌아오면 검색 조건·스크롤·선택한 카드의 초점을 복원합니다.
- 게임 상세(`#p=<id>`): 큰 대표 장면과 상태·제작 정보·참여 역할, 미디어 갤러리, 소개·상세 해설·주요 기능·개발 기록을 담은 사례 페이지입니다. 대표 영상은 클릭해야 재생하며 브라우저 뒤로/앞으로 이동과 직접 링크를 지원합니다.
- 미디어를 누르면 확대 보기(`<dialog>`)가 열립니다. 이미지 원본 비율을 유지하고, 영상 컨트롤·이전/다음·캡션을 제공합니다. 미디어가 없는 게임은 제작 기록 카드와 확인 범위를 표시합니다.
- 평점·리뷰·다운로드 수를 만들지 않습니다. 공개 배포 URL이 없는 게임에는 설치 버튼을 표시하지 않습니다.

## 파일 구성

- `index.html`: 쇼케이스·작품 목록·상세 화면·미디어 확대 보기, 메타·OG 태그
- `styles.css`: 시네마틱 반응형 레이아웃·스크롤 장면·영상 스트립·미디어 전환
- `app.js`: 데이터 렌더링, 해시 라우팅과 상태 복원, 검색·필터·영상 재생 수명주기·미디어 확대 보기·모션 설정
- `games.js`: 프로젝트 설명·특징·검증 상태·개발 이력·해설·미디어 경로(유일한 데이터 원본)
- `fonts/`: 자체 호스팅한 Pretendard Variable(동적 서브셋 CSS + woff2 92조각)과 라이선스
- `media/`: 선별한 WebP 이미지와 H.264 MP4
- `design-options/`: 로컬 디자인 시안 A–D 보관. 운영 사이트에서 참조하거나 배포하지 않습니다.
- `.nojekyll`: 정적 파일 그대로 서비스

## 콘텐츠 변경

`games.js`의 `window.PORTFOLIO.games`에 프로젝트를 추가하거나 수정합니다. 배열 순서가 전체 목록의 순서입니다. 제작 노트는 `window.PORTFOLIO.notes`에 있습니다.

| 필드 | 용도 |
|---|---|
| `id`, `title`, `subtitle`, `engine`, `category`, `status`, `description`, `year` | 기본 정보 |
| `period` | 작업 기간. `YYYY.MM.DD`로 시작(예: `2026.10.29 – 11.05`). 없으면 `year`를 표시 |
| `team` | 팀 프로젝트 표기(예: `팀 프로젝트 · 우당탕`) |
| `role` | 팀 프로젝트에서 맡은 역할(상세의 '역할' 행) |
| `tools` | 제작 도구·AI 활용 표기(문자열 배열) |
| `history` | 개발 이력(문자열 배열, 상세의 '개발 기록') |
| `features` | 주요 특징(문자열 배열) |
| `details` | 작품 해설 `{title, text}` 배열. 상세의 게임 소개 다음에 모든 해설을 표시 |
| `images` | `{src, alt, caption, pos?}` — `pos`는 잘린 썸네일의 초점(`'50% 30%'` 형식) |
| `videos` | `{src, poster, title, caption}` — 갤러리에서 선택하면 확대 보기의 영상 컨트롤로 재생 |
| `final` | 최종 프로젝트(`true`). 첫 화면 최상단 배치, 전용 필터와 상세 표기 |
| `featured` | 대표작. `final`이 아닌 작품만 대표작 섹션에 표시 |

`src`와 `poster`는 `media/` 아래 상대 경로로 지정합니다. 이미지·영상이 없는 프로젝트는 빈 배열을 유지하며 다른 게임의 화면을 대신 쓰지 않습니다.

## 표기 원칙

- **상태**: 직접 실행 확인, 플레이 녹화만 있음, 소스만 있음, 출시·실기기 미검증을 구분합니다.
- **캡션**: 직접 실행 캡처 / 실제 플레이 녹화 프레임 / 프로젝트 내 기존 캡처 / 에디터·자동 검증 화면 / 시네마틱·렌더·컨셉을 명시합니다.
- **AI 활용**: VARCO 3D 생성 모델, 이미지 생성 아트, AI 코딩 에이전트를 쓴 프로젝트는 `tools`와 캡션에 밝힙니다.
- **묶음과 제외**: 같은 게임의 백업·빌드 사본·이전 버전은 한 항목의 개발 이력으로 묶습니다. 빈 템플릿, 공식 샘플, 에셋 스토어 샘플, 외부 오픈소스 도구, 다른 사람의 배포본, 상용 게임은 제외합니다.
- **영구 제외(소유자 요청)**: 빈손의 여행자(THE MEMORY WANDERER), COLOR RUN(ColorRun/RunGame), VARCO FPS LAB(varcotest)은 포트폴리오에 다시 추가하지 않습니다.

## 미디어 출처 메모

- 직접 실행 캡처: 픽셀 전선(WebGL), NECRO CLIMB v1.9, 숲의 수호자(WebGL), 벽 · 참 V17, 설표 컴패니언, LUMI 3D, Lucky Flick Survivor.
- 실제 플레이 녹화에서 추출: 3분, FINAL VERDICT, 먹봇. 다른 참가자 이름·서버 주소가 보이는 장면은 넣지 않았습니다.
- 자동 테스트가 조작한 실행 녹화: LUMI 2D, 말랑이 보호소(캡션에 명시).
- 3분 프로모는 자체 작곡 BGM 편집본을 사용합니다.
- 픽셀 전선 시네마틱과 STAR ELEVEN 번개 영상은 게임 플레이가 아닌 시네마틱입니다.
- 원본 프로젝트, 빌드 실행 파일, 개인 파일, 계정 정보는 게시하지 않습니다. 이미지는 축소하고 메타데이터를 제외했습니다.

## 서체와 라이선스

- Pretendard v1.3.9 (Kil Hyung-jin, https://github.com/orioncactus/pretendard) — SIL Open Font License 1.1. `fonts/LICENSE.txt`에 원문을 보존했고 바닥글에서 링크합니다.
- `fonts/pretendard-variable.css`는 배포본 `pretendardvariable-dynamic-subset.css`의 경로만 `woff2-dynamic-subset/`으로 바꾼 사본입니다. 브라우저는 페이지에 쓰인 글자가 속한 조각만 내려받습니다.
- 실행 중 외부 호스트에 요청하지 않습니다.

## 모션과 접근성

- 모션: 최종작의 방향성 있는 장면 전환과 제목 등장, 스크롤에 따른 영상·주변 캡처의 깊이 변화, 작품별 큰 장면 이동, 가로 영상 스트립, 썸네일에서 확대 보기로 이어지는 전환입니다. 모바일에서는 고정 스크롤 구간을 없애고 연출을 줄입니다.
- 헤더의 **모션 끄기/켜기** 버튼으로 제어하며 `localStorage`의 `gp-motion`에 저장합니다. 저장값이 없으면 운영체제의 동작 줄이기 설정을 따릅니다. 모션을 끄면 자동 재생·자동 전환을 멈추고 내용을 정적으로 표시합니다. 수동 영상 재생은 계속 가능합니다.
- 쇼케이스는 보이는 영상만 재생하고 전환 중에도 최대 두 개만 재생합니다. 대표작 스트립은 마우스 진입·키보드 초점·탭으로 요청한 영상 하나만 미리 봅니다. 화면 밖·다른 화면·확대 보기·숨겨진 탭에서는 배경 재생을 멈춥니다. 영상 로드나 자동 재생에 실패해도 포스터와 안내를 유지합니다.
- 키보드로 게임과 미디어를 열 수 있습니다. 확대 보기는 Escape로 닫고 이전/다음 버튼 또는 방향키로 이동하며, 영상의 기본 컨트롤에 초점이 있으면 방향키를 가로채지 않습니다. 닫을 때 미디어 썸네일에 초점을 돌려줍니다.
