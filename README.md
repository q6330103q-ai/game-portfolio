# 김준식 · Game Archive

직접 만든 게임·프로토타입 27개를 소개하는 정적 포트폴리오. 실제 자료 이미지 102장과 영상 21개를 포함합니다. 설치 의존성, 외부 CDN, 추적 스크립트 없이 GitHub Pages에서 동작합니다.

## 로컬 실행

이 폴더에서 정적 서버를 실행합니다(예: `npx serve .` 또는 `python -m http.server 4173 --bind 127.0.0.1`).

`http://127.0.0.1:4173/` 접속. 파일을 직접 열 수도 있지만 HTTP 서버에서 확인하는 것을 권장합니다.

## 파일 구성

- `index.html`: 한국어 페이지 구조, 검색·쇼릴·프로젝트 상세 대화상자
- `styles.css`: 반응형 레이아웃, 입체 패널, 스크롤·호버 모션
- `app.js`: 검색/카테고리 필터, 갤러리, 영상 탭, 모션 설정과 접근성
- `games.js`: 프로젝트 설명·특징·검증 상태·개발 이력·미디어 경로
- `media/`: 선별한 WebP 이미지와 H.264 MP4
- `.nojekyll`: 정적 파일 그대로 서비스

## 콘텐츠 변경

`games.js`의 `window.PORTFOLIO.games`에 프로젝트를 추가하거나 수정합니다.

| 필드 | 용도 |
|---|---|
| `id`, `title`, `subtitle`, `engine`, `category`, `status`, `description`, `year` | 기본 정보 |
| `features` | 주요 특징(문자열 배열) |
| `period` | 작업 기간(예: `2026.10.29 – 11.05`). 카드에는 연·월만 표시 |
| `team` | 팀 프로젝트 표기(예: `팀 프로젝트 · 우당탕`) |
| `tools` | 제작 도구·AI 활용 표기(문자열 배열) |
| `history` | 개발 이력(문자열 배열, 상세의 DEVLOG) |
| `images` | `{src, alt, caption, pos?}` — `pos`는 카드 썸네일 초점(`'50% 30%'` 형식) |
| `period` | 작업 기간. `YYYY.MM.DD` 로 시작(예: `2026.10.29 – 11.05`). 카드에는 앞 7자(`YYYY.MM`)만 표시 |
| `role` | 팀 프로젝트에서 맡은 역할(상세의 '담당' 행) |
| `featured` | 대표 프로젝트(최대 6개, 배열 순서대로 표시) |

`src`와 `poster`는 `media/` 아래 상대 경로로 지정합니다. 이미지·영상이 없는 프로젝트는 빈 배열을 유지하며 다른 게임의 화면을 대신 쓰지 않습니다. 쇼릴은 배열 순서대로 모든 영상을 모읍니다.

## 표기 원칙

- **상태**: 직접 실행 확인, 플레이 녹화만 있음, 소스만 있음, 출시·실기기 미검증을 구분합니다.
- **캡션**: 직접 실행 캡처 / 실제 플레이 녹화 프레임 / 프로젝트 내 기존 캡처 / 에디터·자동 검증 화면 / 시네마틱·렌더·컨셉을 명시합니다.
- **AI 활용**: VARCO 3D 생성 모델, 이미지 생성 아트, AI 코딩 에이전트를 쓴 프로젝트는 `tools`와 캡션에 밝힙니다.
- **묶음과 제외**: 같은 게임의 백업·빌드 사본·이전 버전은 한 항목의 개발 이력으로 묶습니다. 빈 템플릿, 공식 샘플, 에셋 스토어 샘플, 외부 오픈소스 도구, 다른 사람의 배포본, 상용 게임은 제외합니다.

## 미디어 출처 메모

- 직접 실행 캡처: 픽셀 전선(WebGL), NECRO CLIMB v1.9, 숲의 수호자(WebGL), 벽 · 참 V17, 설표 컴패니언, LUMI 3D, Lucky Flick Survivor.
- 실제 플레이 녹화에서 추출: 3분, FINAL VERDICT, 먹봇. 다른 참가자 이름·서버 주소가 보이는 장면은 넣지 않았습니다.
- 자동 테스트가 조작한 실행 녹화: LUMI 2D, 말랑이 보호소(캡션에 명시).
- 3분 프로모는 자체 작곡 BGM 편집본을 사용합니다.
- 픽셀 전선 시네마틱과 STAR ELEVEN 번개 영상은 게임 플레이가 아닌 시네마틱입니다.
- 원본 프로젝트, 빌드 실행 파일, 개인 파일, 계정 정보는 게시하지 않습니다. 이미지는 축소하고 메타데이터를 제외했습니다.

## 모션과 접근성

헤더의 모션 버튼으로 연출을 끌 수 있으며 설정은 해당 브라우저에 저장합니다. 운영체제의 동작 줄이기 설정을 반영합니다. 상세 대화상자는 키보드와 Escape로 조작할 수 있습니다. 영상은 컨트롤을 제공하며, 탭이 숨겨지거나 모션을 끌 때 재생을 중지합니다.
